# Workbook Templates

This folder contains templates for valuation and PM review workbooks.

`templates/ticker_review.xlsx` is the main PM review template.

The CIQ Standard source template does not belong here. It is:

```text
ciq/templates/ciq_cleandata.xlsx
```

Refreshed CIQ workbooks go in `data/exports/`.

Generated PM review workbooks go in `data/exports/generated/`.

Read [The Excel Template Guide](../docs/handbook/excel-template-guide.md) for more information.
